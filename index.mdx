## Getting started in 3 steps

<Steps>
  <Step title="Install the CLI">
    ```bash
    pipx install action-platform
    ```
    Or open your hosted Hub instance in a browser — no installation needed.
  </Step>
  <Step title="Scaffold your first app">
    ```bash
    action-platform init web python fastapi --name orders --cloud aws/lambda
    ```
    Hub creates a FastAPI project with tests, CI, an IAM policy, and a SAM template — and pushes it to GitHub.
  </Step>
  <Step title="Ship your first release">
    ```bash
    action-platform branch feature 1 hello-world
    git commit -m "feat: say hello"
    action-platform pr
    action-platform release minor
    ```
    A tagged release appears on GitHub with a generated changelog.
  </Step>
</Steps>

<Tip>
  Already have a repository? Run `action-platform install` inside it to add `platform.toml`, git hooks, and CI files without overwriting anything.
</Tip>
